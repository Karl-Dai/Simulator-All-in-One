# 前端检查记录：2026-11-05

本轮检查主入口和八个模拟器前端，修复弹窗误操作、焦点、长内容滚动、窄窗口布局和窗口辨识问题。所有浏览器检查使用新建的独立会话和本地测试端口。原有应用、页面和用户数据保持不变。

## 已修复

- IEC104、OPC UA、Modbus 的确认弹窗：焦点位于取消按钮时，Enter 不再执行确认；中文输入法选择候选词时不触发提交或关闭。
- IEC104 遥控窗口：关闭按钮和高级参数按钮上的 Enter 不再发送控制。
- IEC104 / OPC UA 的 21 个弹窗：补齐初始焦点、Tab 循环、顶层 Escape 关闭及关闭后的焦点恢复。保存期间禁止关闭的弹窗保留原有限制。
- IEC104 连接窗口：展开 TLS / SOCKS5 后，正文独立滚动，底部按钮保持可见。
- Modbus 新增扫描组和写入窗口：补齐键盘交互、防重复提交和长预览滚动；修复扫描组数量标题显示翻译键的问题。
- OPC UA：窄窗口下属性区移到底部，服务端工具栏换行，避免固定三栏挤压内容和裁掉按钮。
- PMU：修复相量数量填小数引发异常、异步失败缺少提示、复选框及标签错位、配置和预设区域在窄窗口下的布局问题。
- 主入口：长错误正文滚动、关闭按钮保持可达；保存设置显示等待状态，旧收藏请求返回时不再覆盖刚选择的主题。
- 八个角色使用不同图标，协议以颜色和符号区分，角色使用 M / S / C 标记；浏览器标题及图标、Tauri 和 Wails 原生构建均接入对应资产。

## Modbus 服务器名称校验开关

按用户要求，新增“校验服务器名称/IP”开关，配置字段为 `VerifyServerName`。新建连接及旧工程缺少该字段时默认关闭，保存并重新打开工程后保留选择。

关闭时仍验证 CA 链、中间证书、有效期和服务端用途，只跳过名称/IP 匹配。开启时使用 Go 标准名称验证。原有显式跳过全部校验选项保持独立；启用该选项时禁用名称开关，但保留其选择。

Modbus 前端 122 项测试、两种尺寸的浏览器点击验证、Go TLS 握手回归和工程保存重开测试通过。使用修改后的 TLS 配置函数进行真实 TLS 1.2 测试，关闭名称校验时读取成功，开启时按预期拒绝缺少 IP SAN 的证书。默认 TLS 协商的 EOF 是独立问题，本次没有添加自动降级逻辑。
