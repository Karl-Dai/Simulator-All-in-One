# SimLab UI 简化与统一

2026-10-30，根据实际使用反馈，将主入口和八个子模拟器统一为黑白灰加少量蓝色。主入口改为四行协议列表，每行直接提供两个角色按钮；移除侧栏、大卡片、重复英文说明、彩色图标底和重复的最近使用区。语言和外观集中到设置页。

## 外观规则

- 本机 UI 字体，数据使用等宽字体；离线运行不加载远程字体。
- 浅色背景 `#fafafa`、表面 `#ffffff`、文字 `#202020`；深色背景 `#181818`、表面 `#242424`、文字 `#ededed`。
- 蓝色用于选中和焦点；协议身份使用中性灰，绿／红／琥珀仅表示有含义的运行状态。
- 4/8 px 间距节奏、6 px 控件圆角，减少嵌套卡片、渐变与装饰边框。
- 保留各协议工作流和独立窗口。主题同步 IPC 只返回外观值，不返回收藏或工程数据。
- 子窗口在可见时每 1.5 秒读取套件外观，回到前台立即刷新。系统主题变化会刷新外观，读取失败保留上次主题并记录警告。
- 工具栏和空状态使用 SVG 线框图标，保留按钮文字、键盘焦点和减少动态效果支持。

## 主入口窗口

- macOS 使用 `mac.TitleBarDefault()`，标题栏与网页内容分开。
- 默认内容大小 960×680，最小 760×560，减少默认窗口过大带来的摆放限制。
- 顶部空白区域设置 `--wails-draggable: drag`；导航、设置按钮及其后代设置 `no-drag`，确保点击不触发窗口拖动。
- 本次已把新构建安装到 `/Applications/SimLab.app` 并重新打开，旧应用保留在 `.validation/neutral-ui/previous-installed-SimLab.app`。用户原有外观、语言、收藏和工程数据保持不变。

## 共享源与维护

`ui/tokens.css`、`ui/components.css`、`ui/Icon.vue`、`ui/theme.ts` 和只读原生外观接口是共享源。它们通过套件补丁进入 `.components/`，不修改原始模拟器开发仓库。

审阅套件克隆中的差异后运行：

```sh
python3 scripts/sync_ui.py --write
python3 scripts/sync_ui.py --check
```

`--write` 同步共享源并重新生成四个补丁，包含套件克隆当前的全部差异，因此必须先审阅。原生构建会核验八角色的共享副本；源码和构建回执继续校验实际文件，不能用旧安装包替代新 UI 构建。
