# 配置保存

启动器和套件内八个模拟器使用相同的 `SQLite` 内嵌数据库，配置保存在用户数据根目录的 `saio.db`。`Windows` 默认目录为 `%APPDATA%\SimLab`；`macOS` 为 `~/Library/Application Support/SimLab`；Linux 为 `${XDG_CONFIG_HOME:-~/.config}/SimLab`。`SIMLAB_DATA_DIR` 可指定绝对路径。便携版更新程序或修复解压缓存时，配置仍保留在这个目录。

创建、编辑、删除和导入配置都会自动保存。界面设置与连续表单输入会合并短时间内的修改，并显示保存状态。保存失败会保留提示；读取配置失败会阻止默认值写入，请修复问题后重新启动程序。同一角色的多个窗口修改同一文档时，后保存的旧状态会收到冲突提示，需重新打开程序读取最新配置。

恢复配置后，连接、监听服务和仿真任务保持停止。实时采样、通信日志、图表历史不会随采样持续写入配置库。

首次打开新版时自动读取原自动保存文件及界面本地设置，只在数据库没有对应文档时迁移。原文件保留。旧版没有自动保存过的工程需要手动导入。升级前请关闭旧模拟器窗口，避免旧版继续修改已迁移的文件。

手动保存用于导出工程副本，统一使用 `.saioproj`。工程文件也是 `SQLite`，但只包含所选角色及文档，不包含其他模拟器的配置。原 JSON、Modbus 和 `OPC UA` 工程仍可导入。`PMU` 主站可导入导出连接配置；子站可分别选择站配置、预设或数据生成设置。

证书、密钥和回放数据仍保留外部文件引用。移动工程时需同时保留这些资源可访问的路径。数据库格式不提供加密。

运行中的共享数据库可能同时有 `saio.db-wal` 和 `saio.db-shm` 事务文件。不要只复制正在使用的 `saio.db` 作为完整备份；复制数据目录前应关闭套件及所有模拟器。导出的 `.saioproj` 是独立单文件。

存储格式及自动化验证见 [`storage/CONTRACT.md`](../storage/CONTRACT.md) 和 [`storage/VALIDATION.md`](../storage/VALIDATION.md)。
