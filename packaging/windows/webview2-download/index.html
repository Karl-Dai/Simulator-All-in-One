Microsoft Edge WebView2 运行库

SAIO 和内置模拟器使用 WebView2 显示 Windows 界面。若已能正常打开程序，无需重复安装。

下载 Windows x64 离线安装包（204 MB）

  1. 下载安装包并运行，按微软安装提示完成操作。
  2. 重新打开 SAIO 的便携 EXE。

这是微软运行库的一次性安装。SAIO 本身无需安装；它包含全部八个模拟器，不捆绑 WebView2。

离线电脑：先在可联网电脑下载安装包，再拷贝到目标电脑安装。

WebView2 Runtime for Windows

SAIO uses Microsoft Edge WebView2 to display its windows. If SAIO opens normally, no additional installation is needed.

Download the Windows x64 offline installer (204 MB). Install it once, then reopen the portable SAIO EXE. For offline PCs, copy this installer from a connected computer first.

SAIO itself requires no installation and includes all eight simulators. WebView2 is a separate prerequisite.
